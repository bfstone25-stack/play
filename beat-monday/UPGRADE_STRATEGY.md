# BEAT MONDAY / 打爆周一 升级策略

更新基线：v2.0，2026-08-22

## 产品定位

Beat Monday（中文《打爆周一》、日文《月曜撃破》）是一款办公室题材的 2D 格斗。不是自动射击，而是街机对打：站位、出拳、踢腿、必杀，把周一从会议室打出门外。

## 产品结构

- **战役 / CAMPAIGN**：办公室政治五连战。实习生 Riley → 产品 Morgan → HR Pat → 财务 Avery → 总监 Vale。每战前有一段职场故事。
- **对战 / VERSUS**：单挑任一对手，练手感。
- 每场两局先胜，每局 60 秒。超时比血。
- 气槽攒满可放超级。必杀有硬直，不是乱按必赢。

## 玩法原则

- 玩家自己出招。没有自动开火，没有虫群。
- 同一输入在同一帧产生同一判定（表现层粒子除外）。
- 难度来自读招、距离和硬直，不靠隐藏规则或付费复活。
- 离线可玩。不引入 LLM。

## 语言与品牌

- 英文、西班牙文、巴西葡萄牙文统一使用标题 **BEAT MONDAY**。
- 简体中文使用 **打爆周一**；日文使用 **月曜撃破**。
- 语言顺序：EN → ES → PT → 中文 → 日本語。
- 语气好笑且英勇。HUD 用街机口吻：ROUND、FIGHT、KO、YOU WIN。

## 视觉与声音

- 调色锁定：红 `#e23b2f`、钴 `#1e4cff`、黄 `#f5d031`、黑 `#0a0b10`。
- 侧视办公室擂台。角色用手绘 canvas，体型要大，要像格斗家，不要小点。
- 尊重 `prefers-reduced-motion`：关超级定格和强震动。
- 声音：出拳、踢腿、必杀、KO、荧光灯低频。

## 留存与商业

- 街机通关负责完成感，对战负责手感回访。
- 永久无广告，不碰 gacha。

## 数据运营

- 漏斗：访问 → 语言 → 标题 → 街机/对战 → 首击 → KO → 通关/失败 → 分享。
- 统计：语言、对手、回合、剩余血、是否超级、分享。

## 后续迭代守则

1. 新角色必须有站姿、受伤、至少两套攻击和一种必杀。
2. 保持键位与虚拟键可读，攻击键不小于 44px。
3. 不复制 Street Fighter 的标志、语音、角色或关卡美术。
