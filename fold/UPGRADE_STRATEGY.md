# FOLD / 归一 升级策略

更新基线：v0.3，2026-07-29

## 产品定位

FOLD（中文《归一》、日文《帰一》）是一款面向全球市场的确定性几何推理游戏。核心不是随机堆叠数字，而是观察空间、选择方向，让所有元素在尽可能少的移动中合而为一。

## 产品结构

- **精选 / CURATED**：51 个经过验证的固定谜题，建立学习曲线与完成感。
- **无尽 / ENDLESS**：150 个离线生成、可验证的扩展谜题，承接长时挑战。
- 每关以目标值、步数和三星基准衡量结果；关卡规则必须确定、可复现、可离线游玩。
- 后续可增加“每日一折”，但每日题必须对所有玩家一致，并与精选、无尽成绩分开。

## 玩法原则

- 同一输入在同一局面中永远产生同一结果。
- 关卡发布前必须由求解器验证可解，并记录最优或可信的基准步数。
- 难度来自空间结构、阻挡和移动顺序，不依靠随机惩罚、时间压力或隐藏规则。
- 优先改善关卡曲线、操作反馈和撤销体验，不引入 LLM 或联网依赖。

## 语言与品牌

- 英文、西班牙文、巴西葡萄牙文统一使用标题 **FOLD**。
- 简体中文使用 **归一**；日文使用本地字形 **帰一**。二者以 FOLD 作为小型英文识别标。
- 语言顺序：EN → ES → PT → 中文 → 日本語。
- 标题语义保持“折叠、合并、万象归一”，避免普通 2048 仿品式表达。

## 视觉与声音

- 标题画面使用原创实时 SVG 几何动画：多边形、圆、轴线与折叠核心围绕同一中心运动。
- 视觉采用墨黑、纸白、旧金与克制的青灰；中文和日文使用宋体/明朝体式东方字标、留白与不完全对称。
- 游戏内保持几何清晰度优先，装饰不得妨碍数字、墙体、目标和移动反馈。
- 尊重 `prefers-reduced-motion`；标题动画不依赖视频或大体积素材。
- 后续声音应围绕木、石、纸、金属的短促触感设计，在合并、完美归一和结算时形成递进，不持续铺满音乐。

## 留存与商业

- 精选负责教学与完成感，无尽负责挑战和长时游玩；“每日一折”负责低负担回访。
- 奖励围绕最少步数、连续完成、全三星和每日解题展开，不使用体力、强制广告或随机付费。
- 评价入口以“留墨 / Reflect”叙事包装，保持与禅意几何视觉一致。
- 永久无广告；先验证完成率、回访率和关卡质量，再决定支持者主题等一次性付费内容。

## 数据运营

- 漏斗：访问 → 语言 → 标题页 → 入局 → 开关卡 → 首次移动 → 完成 → 下一关/重试 → 分享/评价。
- 统计维度：语言、关卡、精选/无尽、步数、星级、基准步数、完成率、撤销、重置、分享和评价。
- 只记录聚合所需的游戏行为；不记录棋盘逐步回放、剪贴板内容或评价正文到通用事件流。
- 历史缺少完整维度的数据标记为 `legacy`，不得错误归因到新漏斗。

## 后续迭代守则

1. 新关卡必须先通过确定性求解与最短路径校验。
2. 新功能必须保持离线可玩，并接入对应漏斗事件。
3. 所有语言沿用统一 FOLD / 归一品牌系统与信息层级。
4. 保持移动端单手操作、数字可读性和低动效无障碍支持。
5. 不复制 2048 或现有禅意游戏的标志、音乐与美术资产。
