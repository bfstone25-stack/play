# 赛博木鱼 · Cyber Merit

A futuristic cyber-Buddhist wooden-fish altar. Strike the mokugyo, stack digital merit, and fill today's lotus / circuit mandala.

Cabinet 07 on blazeCore Play. Static app — no backend, no `/kernel/*`.

## Play

1. Enter the shrine. Tap the fish or press Space.
2. Hit the incense pulse for combo. Missing still pays — this is a clicker.
3. Fill the mandala to complete a liturgy. Spend merit to change the altar.
4. Read today's koan. Hang ofuda. Listen to 梵音.

Open `frontend/index.html` locally, or mount the folder as the static app `cyber-merit`.

## Verify

```bash
node cyber-merit-smoke.cjs
```
