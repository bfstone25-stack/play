# GHOST CHANNEL

Browser radio-command game for **Brackeys Game Jam 2026.2**.

- Jam: https://itch.io/jam/brackeys-16
- Theme: **Trust no one**
- Play: open `index.html` (or any static server)

You are Overwatch for five fireteams. One voice on the net is a mimic. Authorize, deny, or interrogate. When the channel goes quiet, name the ghost.

Anonymous play telemetry (funnel, viewport, win/lose reason) posts to `apps.blazecore.dev`. No accounts. See `ops/intel/TEL.md`.

All art and audio are original runtime code (Canvas + Web Audio). No stock assets and no generative image/audio models.
